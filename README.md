# AI jamoa — Claude plugini

vibecoding.uz «AI xodimlar» praktikumi uchun. Claude bilan ~10 daqiqalik tanlovli savol-javob: biznesingizdagi ishlarni
ko'rib chiqadi va qaysi ishni qaysi AI xodim olishini, qanday nazorat bilan va qaysi tartibda joriy qilishni aniqlaydi.
Natija — interaktiv xarita: AI jamoa, har agent qanday ishlaydi, sizdan nima kerak, 0-hafta → 3-oy yo'l xaritasi va
nusxa olinadigan yo'riqnomalar. Oxirida birinchi AI xodimingizni tayyor skill qilib beradi.

## O'rnatish

**claude.ai yoki Claude desktop:** Customize → Plugins → Add marketplace → `iakadirov/ai-jamoa` → **ai-jamoa** → Install.
Yoki [Releases](https://github.com/iakadirov/ai-jamoa/releases) dan `ai-jamoa.zip` ni yuklab, **Upload plugin** orqali qo'shing.
Settings → Capabilities → **Code execution and file creation** yoqiq bo'lsin.

**Claude Code:**

```
/plugin install ai-jamoa --marketplace iakadirov/ai-jamoa
```

## Ishlatish

Yangi chatda `/` → **diagnostika** (yoki «AI jamoa diagnostikasini boshlaymiz»). Keyin `/` → **ai-xodim**.
